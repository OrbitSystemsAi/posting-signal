# PostingSignal

Local-first LinkedIn planning, drafting, media, approval, and publishing workspace.

- Web application: `http://127.0.0.1:3004`
- Local Canva/document API: `http://127.0.0.1:3001`

```bash
npm install
npm run dev
```

Existing browser content is read from the original `signal-posts` local-storage
key so it remains available on the same local origin.
